# 🍔 Food Ordering System (Java)

## 📌 Overview

The **Food Ordering System** is a console-based Java application developed using **Core Java** and **Object-Oriented Programming (OOP)** principles. It simulates a basic online food ordering process where users can browse the food menu, place orders, view their order summary, and complete the checkout process.

This project is ideal for beginners, B.Tech students, and Java learners who want to strengthen their programming skills while creating a practical GitHub project for internships and placement preparation.

---

## ✨ Features

* 🍕 View Food Menu
* 🛒 Order Food Items
* 📋 View Order Summary
* 💳 Checkout and Bill Calculation
* 🖥️ Menu-Driven Console Interface

## ▶️ How to Run

1. Save the file as `FoodOrderingSystem.java`.
2. Open a terminal or command prompt.
3. Compile the program:

```bash
javac FoodOrderingSystem.java
```

4. Run the program:

```bash
java FoodOrderingSystem
```
